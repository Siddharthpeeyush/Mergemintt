Frequently asked questions

Quick answers about MergeMint.

Is MergeMint really free?

Yes. All tools are free to use with no watermarks and no sign-up. We plan to keep basic tools free forever, supported by ads.

Are my files uploaded to your servers?

No. Every tool runs entirely in your browser using JavaScript. Your files are never sent to us or anyone else — you can verify this by watching your network tab, or by disconnecting from the internet after the page loads.

Is there a file size limit?

There is no server-side limit, since nothing is uploaded. Very large files (hundreds of MB) may be slow or run out of memory on low-end devices, because processing happens on your own device.

Which browsers are supported?

Any modern browser: Chrome, Edge, Firefox, Safari and their mobile versions. JavaScript must be enabled.

Do the tools work on mobile?

Yes — the site is fully responsive and the tools work on phones and tablets.
