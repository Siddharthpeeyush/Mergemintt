    Frequently asked questions

    Why did my file download as .aspx instead of PDF?

    Many Indian government and university websites serve documents through pages ending in .aspx. Your browser saves the file with that extension, but the content inside is usually a perfectly good PDF file.

    How do I convert an ASPX file to PDF?

    Upload the .aspx file to MergeMint's free ASPX to PDF tool. It inspects the file: if the content is actually a PDF, you get it back as a proper .pdf file you can open anywhere.

    Is it safe to upload my ASPX file here?

    Yes. The file is inspected entirely in your browser and never uploaded to any server, so admit cards and application forms stay private.

    What if my ASPX file is not actually a PDF?

    The tool tells you what the file really is. If it's a web page instead of a document, you'll see that clearly rather than getting a broken file.

    Can I open ASPX files on my phone?

    Yes. Upload the .aspx file in your mobile browser and download the converted PDF directly to your phone.
